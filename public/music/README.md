# SudekiMP launcher music

`Map Inversion.mp3` is an optional, user-supplied track for the Windows beta
launcher. It is not included in the Windows download. When the user presses
**Play project music**, the launcher reads `manifest.txt`, downloads the track
from this public directory over HTTPS to its local cache, and plays it inside
the launcher.

Developer: [wander](https://git.unfilteredrealm.com/wander)
