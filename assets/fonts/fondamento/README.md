# Title-menu lettering

Unmodified Fondamento Regular by Brian J. Bonislawsky / Astigmatic, licensed
under SIL OFL 1.1. Include OFL.txt when packaging this font or its embedded data.
Source: https://github.com/google/fonts/tree/main/ofl/fondamento
Font SHA256: ee03a7ccb3b7cdf3cd095d0cc34f9e70c16b1779cbc7c466bf9077323a6ea764

This is a stylistic approximation, not an identification of Sudeki's original
baked title wordmarks. It supplies consistent lettering for every replacement
button. The game font assets are not bundled.

`python3 tools/generate_title_font.py` rebuilds the checked-in English label
atlas with Pillow. The DLL embeds the atlas and needs no installed system font.
The title adapter leaves other game languages on their native presentation.
